# 5.8 没有银弹

你得明白，采纳这些习惯并不保证你能成为一个成功的模式写作者。
这份清单也不周全——Meszaros 与 Doble 尤其如此，他们走得更远 [MD98](../biblio.md#md98)。
但它至少能帮你把力气用在有回报的地方。
你的模式越好，影响就越大。

> 译注：Meszaros 与 Doble 的文章《A pattern language for pattern writing》（收录于 [MRB98](../biblio.md#mrb98)）用一套模式语言来总结写模式的经验，比本章这七条习惯更系统，所以作者说他们 "走得更远"。

这并不是说人人都该去写模式。
写模式需要投入相当的时间与精力，也并非人人都觉得值得。
我鼓励每个人试写一两个模式，否则你无从知道自己擅长不擅长。
不过，随着时间推移，我预计模式 *写作者* 的人数会被模式 *使用者* 远远盖过——就像编程语言的使用者（谢天谢地）远远多于语言的创造者一样。
