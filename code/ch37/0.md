# 第 37 章 永不停止学习

> 10. 我将永不停止学习和改进我的手艺。

程序员永不停止学习。

我相信你听说过你应该每年学习一门新语言。
是的，你应该。
一个好的程序员应该了解大约十几种语言。

不仅仅是同一种语言的十几种变体。
不仅仅是 C、C++、Java 和 C#。
相反，你应该了解许多不同家族的语言。

你应该了解一种静态类型语言，如 Java 或 C#。
你应该了解一种过程式语言，如 C 或 Pascal。
你应该了解一种逻辑语言，如 Prolog。
你应该了解一种栈语言，如 Forth。
你应该了解一种动态类型语言，如 Ruby。
你应该了解一种函数式语言，如 Clojure 或 Haskell。

你还应该了解几种不同的框架。
以及几种不同的设计方法论，和几种不同的开发过程。

我并不是说你应该成为所有这些方面的专家；但你应该努力让自己接触它们，不仅仅是在肤浅的层面上。

事实上，你应该类似地接触的东西列表几乎是无穷无尽的。
我们的行业在几十年里经历了快速变化，那种变化很可能还会持续一段时间。
你必须跟上它。

这意味着你必须继续学习。
继续阅读书籍和博客。
继续看视频。
继续参加会议和用户组。
继续参加培训课程。
继续学习。

关注过去的珍贵作品。
60 年代、70 年代和 80 年代写的书是洞察力和信息的绝佳来源。
不要陷入认为所有那些旧东西都过时的陷阱。
我们行业中实际过时的东西并不多。
尊重那些在你之前的人的付出和成就，并研究他们的建议和结论。

不要陷入认为培训你是雇主的工作的陷阱。
这是你的职业；你必须为它负责。
学习是你的工作。
弄清楚你应该学习什么是你的工作。

如果你足够幸运，在一家会为你买书、送你去参加会议和培训课程的公司工作，那么充分利用它。
如果不是，那么自己为那些书、会议和课程付费。

并计划在这方面花一些时间。
每周花一些时间。

你每周欠你的雇主 35 到 40 小时。
你欠你的职业另外 10 到 20 小时。

这就是专业人士的做法。
专业人士花时间培养和维护他们的职业。
这意味着你总共应该每周工作 50 到 60 小时。
主要在工作场所，但也有很多在家里。
