# 第 34 章 团队协作

> 7. 我将持续确保其他人可以替代我，我也可以替代他们。

想象一支足球队的球员将球带向球门。
想象在一次进攻中，其中一个球员绊倒摔倒了。
他的队友们会怎么做？
他们填补空缺，堵住漏洞，并继续将球带向球门。

海军舰艇上的水手们每个人都有各自的工作，但他们也知道如何做别人的工作。
为什么？
因为在激烈的战斗中，一个水手可能会倒下。
另一个水手必须能够填补空缺，让舰船继续战斗。

在软件团队中也是如此。
事实上，这就是我们称之为团队的原因。
如果团队中的某个成员因任何原因倒下，团队中的其他人必须能够填补空缺，填补那个漏洞，并保持项目在正确的轨道上。

## 协作编程

将知识隔离在孤岛中对团队和组织极其有害。
一个人的损失可能意味着整个知识部分的损失。
它可能使团队和组织陷入瘫痪。
这也意味着团队中的个人没有足够的上下文来相互理解。
他们常常互相说不到一块去。

解决这个问题的方法是在团队中传播知识。
确保每个团队成员都了解其他团队成员正在执行的工作的很多内容。

传播知识的最好方法是一起工作——结对或群聚。

事实是，几乎没有比协作编程更好的方法来提高团队的生产力了。
因为一个了解正在完成的工作之间深层联系的团队必然比一群孤岛更具生产力。

## 开放式/虚拟办公室

团队成员之间频繁地看到彼此并进行互动也很重要。
实现这一目标的最好方法是将他们放在一个房间里。

在 21 世纪初，我拥有一家公司，帮助组织采用敏捷开发。
我们会派遣一组讲师和教练到那些公司，并指导他们完成变革。
在每次参与开始之前，我们告诉经理们重新安排办公空间，以便我们将要指导的团队在他们自己的团队房间里一起工作。

不止一次，在我们到达开始指导之前，经理们告诉我们，团队已经更加高效了，仅仅是因为他们在同一个房间里一起工作。

我在 2021 年第一季度写了本章的第一版。
COVID-19 疫情开始减弱，我们都期待着恢复正常生活。
但疫情在其后留下了大量远程工作的软件团队。

远程工作永远无法像在同一个房间里一起工作那样高效。
即使有最好的电子辅助，在屏幕上看到彼此也不如亲自看到彼此好。
尽管如此，现在的协作电子系统已经非常好了。
所以，如果你在远程工作，使用它们。

创建一个虚拟团队房间。
保持每个人的脸在视野中。
保持每个人的音频通道尽可能开放。
你的目标是创建一个团队房间的幻觉，让每个人都在其中一起工作。

结对和群聚现在享有大量的电子支持。
远距离共享屏幕和一起编程相对容易。
当你这样做时，保持面部和音频开启和运行。
你想在协作代码时能够看到彼此。

远程团队应该尽最大努力保持相同的工作时间。
当程序员有巨大的东西分布时，这非常困难。
所以尽量保持每个团队中的时区数量尽可能少，并努力每天至少有六个连续小时，每个人都可以在虚拟团队房间中在一起。

你有没有注意到在开车时对其他司机大喊大叫是多么容易？
这是挡风玻璃效应。
当你坐在挡风玻璃后面时，很容易把别人看作是傻瓜、白痴，甚至是敌人。
很容易使他们失去人性。
这种效应在电脑屏幕后面也会发生，程度较轻。

所以团队应该每年几次在同一个物理房间里聚在一起。
我建议每季度一周。
这将帮助团队凝结并保持其作为一个团队。很难与两周前一起吃午饭并实际合作过的人陷入挡风玻璃陷阱。
