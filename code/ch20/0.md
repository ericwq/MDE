# 第 20 章 组件原则

<center><img src="../imgs/fig-ch20-0.png" width="40%"></center><br/>

如果说 SOLID 原则告诉我们如何将砖块排列成墙壁和房间，那么组件原则则告诉我们如何将房间排列成建筑。
大型软件系统，就像大型建筑一样，是由较小的组件构建而成的。

在本章中，我们将讨论什么是软件组件，它们应该由哪些元素组成，以及它们应该如何组合成系统。

本章是一个概述。
这些原则在 [PPP02](../bib.md#ppp02) 以及 [Clean Arch](../bib.md#clean-arch) 中有详细描述。
