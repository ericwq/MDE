## 组件

<ins>组件是部署的单元。
它们是作为系统的一部分可以部署的最小实体</ins>。
在 Java 中，它们是 jar 文件。
在 Ruby 中，它们是 gem 文件。
在 .NET 中，它们是 DLL。
在编译型语言中，它们是二进制文件的聚合。
在解释型语言中，它们是源文件的聚合。
在所有语言中，它们都是部署的粒度。

组件可以链接成一个单独的可执行文件。
或者它们可以聚合到一个单独的归档文件中，例如 `.war` 文件。
或者它们可以作为独立的、动态加载的插件独立部署，例如 `.jar`、`.dll` 或 `.exe` 文件。
<ins>然而，无论它们最终如何部署，设计良好的组件总是保留独立可部署的能力，因此也是独立可开发的能力</ins>。
