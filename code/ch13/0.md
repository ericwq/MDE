# 第 13 章 整洁类

作者：Jeff Langr

在 [第 7 章](../ch7/0.md) “整洁函数” 中，你学习了如何最好地以函数或方法的形式组织代码语句和表达式。
希望你已经学到了关于整洁函数的这些重要内容：

- 函数提供了一种声明、调用和复用逻辑行为或概念片段的方法。
- 虽然没有什么能阻止你将多个概念聚合到一个函数中，但如果你组合那些捕获小的、离散概念的方法，你会好得多。

在本章中，你将在更高一层的组织结构 ——类或模块—— 中听到 [第 7 章](../ch7/0.md) 建议的回声。

你的编程语言允许你将概念分组到一个单一的构造中 —— 如果你使用面向对象语言编码，那就是一个类。
如果你主要使用像 JavaScript、Elixir 或 F# 这样的函数式语言编程，你可能会称之为模块。
