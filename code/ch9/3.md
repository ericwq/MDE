## 结论

这是整洁的吗？
我对它相当满意，尽管我不是一个 Python 程序员，所以我可能违反了很多约定，并且可能没有使用最高效的技术。
尽管如此，我认为已经实现了一些主要目标。
我们已经将系统划分为至少四个主要组件：`main`、`TaxCalculator`、`TaxBracketter` 和 `BadBobAdjuster`。
并且我们将这些组件放在了适当的架构边界后面。

我们的测试经受住了大量的更改，并证明了它们的韧性。
我们的基本算法也是如此。
对一个算法的更改不太可能影响其他算法。
我们还通过使用表驱动算法内置了一些灵活性。

随着测试变得更加具体，生产代码变得更加通用。

有些人可能会抱怨这些名称。
我不知道，我有点喜欢 `TaxBracketter` ⁶ 和 `BadBobAdjuster`。
但如果你玩这些代码，你可能会找到一些更好的名称。

⁶ 尽管拼写有误。

我必须说，我对 IntelliJ 的 Python 插件和 Copilot 帮助一个 20 多年没写过 Python 的人的能力感到满意。
我还必须说，测试的响应速度给我留下了深刻的印象。
我已经习惯了 JVM 的启动时间，而测试结果在我的手指离开测试按钮之前就出现在屏幕上，这是一种快乐。
