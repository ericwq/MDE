# 第 10 章 一件事

<center><img src="../imgs/fig-ch10-0.png" width="40%" /></center><br/>

你还记得 Bjarne Stroustrup 关于整洁代码说了什么吗？
他说：“整洁代码只做好一件事。”
事实上，多年来许多其他软件作者也说过类似的话。
这句话的问题在于：*“一件事”* 意味着什么？

正如我在前一章中所说，我曾经负责过一个 3000 行长的 C 函数。
它被命名为 `gi`，代表图形解释器。如果有人挑战我，问我那个 3000 行的函数是否只做一件事，我会自信地回答：“当然！它解释图形。”

当然，一个 3000 行的函数在解释图形时肯定在做很多事情。
我相当相信，解释图形的问题可以被分解成相当多的事情。

那么我们如何解决这个问题呢？
如果要遵循这个建议，我们必须对 “一件事” 有一个合理的定义。
我想我知道那个定义是什么，我现在就告诉你。

但是，就像 Deep Thought 在《银河系漫游指南》中所说的：“你不会喜欢它的。”
