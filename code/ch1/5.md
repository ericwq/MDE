## **童子军规则**

仅仅把代码写好是不够的。
代码必须随着时间的推移保持整洁。
我们都见过代码随着时间腐烂和退化。
所以我们必须采取积极的行动来防止这种退化。

美国童子军有一条简单的规则，我们可以应用于我们的职业：

> 离开营地时要比你发现它时更干净。

如果我们每次签入代码时，都让它比我们签出时更干净一些，那么代码根本不可能腐烂。

> 以比你签出时更干净的状态签入代码。

清理不一定是大事。
只需做一件小小的、随意的善举。
改进一个变量名，分解一个有点过大的函数，消除一小点重复，清理一个复合的 if 语句。

你能想象在一个团队中每个成员都实践这条规则的项目上工作吗？
随着时间的推移，代码只会变得更好。
你认为还有其他选择能称得上专业吗？
事实上，持续改进不正是专业精神 ——作为一个有道德的人—— 的内在组成部分吗？
