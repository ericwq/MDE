编写整洁的并发程序是很难的 —— 非常难。
编写在单线程中执行的代码要容易得多。
编写表面上看起来不错但在更深层次上有问题的多线程代码也很容易。
这样的代码在系统承受压力之前一直工作正常。

在本章中，我们讨论并发编程的必要性及其带来的困难。
然后，我们提出几个处理这些困难和编写整洁并发代码的建议。
最后，我们总结与测试并发代码相关的问题。

整洁的并发是一个复杂的话题，值得单独写一本书。
我们在本章中的策略是提供一个概述。
