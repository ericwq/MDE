## 了解你的语言和库

以下是一些额外的建议：

- 使用提供的线程安全集合。
- 使用线程框架（例如 Java 中的 Executor）来执行不相关的任务。
- 尽可能使用非阻塞解决方案。
- 了解哪些库模块是线程安全的，哪些不是。

### 线程安全集合

当 Java 还年轻的时候，Doug Lea 撰写了开创性的著作《Java 并发编程》⁴ 。
除了这本书，他还开发了几个线程安全的集合，这些集合后来成为 JDK 中 `java.util.concurrent` 包的一部分。
该包中的集合在多线程情况下是安全的，并且性能良好。
事实上，`ConcurrentHashMap` 的实现几乎在所有情况下都比 `HashMap` 表现更好。
它还允许同时进行并发读取和写入，并具有支持常见的复合操作的方法，否则这些操作不是线程安全的。
如果 Java 是部署环境，从 `ConcurrentHashMap` 开始。

⁴ [Lea99](../bib.md#lea99) 。

还有其他几种类被添加以支持高级并发设计。
以下是 Java 中的一些示例：

```markdown
| 类名            | 描述                                                                 |
| --------------- | -------------------------------------------------------------------- |
| ReentrantLock   | 一种可在一个方法中获取、在另一个方法中释放的锁。                     |
| Semaphore       | 经典信号量的实现，带有计数器的锁。                                   |
| CountDownLatch  | 等待若干事件完成后，唤醒所有等待在此锁上的线程。<br>它能让所有线程拥有大致同时启动的均等机会。 |
```

**建议**： 审查你可用的类。
对于 Java，熟悉 `java.util.concurrent`、`java.util.concurrent.atomic` 和 `java.util.concurrent.locks`。
