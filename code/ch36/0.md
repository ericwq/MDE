# 第 36 章 尊重程序员同行

> 9. 我将尊重我的程序员同行，因为他们的伦理、标准、纪律和技能。
在我对同行程序员的尊重中，任何其他属性或特征都不会成为因素。

我们，软件专业人士，接受我们手艺的沉重负担。
我们勇敢的人是男性和女性，异性恋和同性恋，黑色、棕色、黄色和白色，共和党人、民主党人、宗教信徒和无神论者。
我们是人类，以人类所有的多种形式和种类存在。
我们是一个社区 ——一个兄弟会—— 相互尊重。

进入我们兄弟会并获得该兄弟会每个成员的接纳和尊重的唯一资格，是我们职业的技能、纪律、标准和伦理。
没有其他人类属性值得考虑。
不能容忍任何其他基础上的歧视。

在我们的职业中，我们首先是程序员。
