# 第 33 章 保持高生产力

> 6. 我将尽我所能，使自己和他人保持尽可能高的生产力。
我不会做任何降低生产力的事情。

生产力。
这是一个相当宏大的话题，不是吗。
你多久感觉一次这是你工作中唯一重要的事情？
如果你想想，生产力就是这本书，以及我所有关于软件的书籍，所要讲述的内容。

它们是关于如何快速前进的。

而我们在过去八十年的软件中学到的是，快速前进的方式是做好。

> 快速前进的唯一方法就是做好。

所以你保持你的代码整洁。
你保持你的设计整洁。
你编写语义稳定的测试并保持高覆盖率。
你知道并使用适当的设计模式。
你保持你的方法小巧，你的名称精确。

但这些都是实现生产力的间接方法。
在本章中，我们将讨论保持高生产力的更直接方法：

- *粘性 (Viscosity)* ：保持你的开发环境高效
- *管理干扰 (Managing distractions)* ：处理日常业务和个人生活
- *时间管理 (Time management)* ：有效地将生产性时间与所有你必须做的其他琐事分开
