# 审查精炼器

## 这将产出什么

- **输出**：`.lattice/standards/review-standards.md`
- **两种模式**：叠加（默认）和覆盖
- **配置键**：`paths.review_standards`
- **消费者**：审查分子（非原子——这是首个分子级配置）
- **模板**：读取 `./assets/template.md`

### 范围澄清

此精炼器配置审查*流程*——审查分子如何编排原子输出。它不配置原子检查什么。

| 属于这里（流程编排） | 属于原子精炼器（质量标准） |
|---|---|
| 加载哪些原子及何时加载 | 原子运行什么检查 |
| 严重性级别定义 | 什么构成违规 |
| 报告格式和分组 | 清单项和反模式 |
| 差异范围规则 | 层级定义、命名规则 |
| 洞察捕获偏好 | 领域建模规则 |
| 健康日志格式 | 安全检查阈值 |
| 自定义审查维度 | 原子特定验证逻辑 |
