# 安全编码：默认原则

可通过 `.lattice/config.yaml` 中的自定义文档覆盖。

## 1. 信任边界识别

信任边界 = 数据跨越信任级别。首先找到这些。

### 常见信任边界

不受信任端（浏览器/移动应用、外部 API、数据库）→ 信任边界（控制器、应用服务、仓库）→ 受信任端。

### 边界识别清单

对每个函数/模块：数据来自何处？已验证过吗？可能被篡改吗？来自另一个服务吗？

## 2. 输入验证模式

在边界处使用允许列表验证。拒绝不良数据后再传播。验证格式、存在性和业务规则。

## 3. 参数化查询模式

始终使用参数化查询或 ORM 查询构建器。绝不将用户输入拼接到 SQL 中。

## 4. 按上下文的输出编码

HTML 上下文 → HTML 实体编码。JSON → JSON 序列化。URL → URL 编码。

## 5. 授权检查模式

在服务层验证授权，而不仅是控制器。每个端点强制执行最小权限。

## 6. 密钥管理模式

使用环境变量或密钥管理器。绝不在源代码中硬编码密钥、密码或令牌。

## 7. 注入防护模式

命令注入：避免 shell 执行；如不可避免则严格限制允许列表。LDAP/XML/路径遍历注入同理。
