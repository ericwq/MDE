# 前言

自从架构宇航员们发现了另一个可以脱离务实精神、冲向企业宇宙的 “模因” 以来，Web 服务的世界便一直处于奔向超新星的快车道上。
但值得庆幸的是，一切并未就此终结。
一场对 HTTP 重新审视的复兴运动正在兴起，并在 REST 的旗帜下，展示了对于那些复杂性的兜售者试图强行塞给所有人的东西的一种可信替代方案 —— 一套简单的原则，普通开发者每天都可以用来以 Web 原生风格连接应用程序。

《RESTful Web Services》向您展示了如何使用这些原则，而无需那些戏剧性的场面、晦涩的术语和层层迂回的间接层 —— 这些东西曾吓倒了一代 Web 开发者，让他们认为 Web 服务如此困难，以至于必须依赖大厂实现才能完成任何工作。
每一位从事 Web 开发的开发者都需要阅读这本书。

<p align="right">——David Heinemeier Hansson</p>
