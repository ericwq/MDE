# 第 3 部分 基础知识

在接下来的这组设计模式中，我们将不再着眼于解决某个特定的、范围狭窄的问题，而是探讨适用于几乎所有 API 的更广泛的主题。
这些核心设计模式将为设计优秀的 API 奠定基础，同时我们也将把它们作为后续设计模式的构建模块。

在 [第 6 章](ch6.md) 中，我们将首先探讨如何为 API 中的资源提供唯一标识。
然后，在 [第 7 章](ch7.md) 至 [第 9 章](ch9.md) 中，我们将定义一组核心交互模式，包括标准方法和自定义方法（同时了解这些方法在操作资源子集时的应用）。
在 [第 10 章](ch10.md) 中，我们将学习如何使用 LRO（长期运行的操作）来处理可能需要很长时间才能完成的 API 方法，
最后，[第 11 章](ch11.md) 将介绍如何使用可重复运行作业来管理 API 中的重复性工作。
