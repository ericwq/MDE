# 第 4 部分 资源关系

在我们设计的任何 API 中，不同的组件需要以不同的方式相互关联。
在接下来的几章中，我们将研究资源可以关联的各种方式，以及如何设计正确的 API 方法，让用户能够管理资源之间的这些关系。

首先，在 [第 12 章](ch12.md) 中，我们将研究一种特殊类型的资源，称为单例子资源，以及我们如何依赖这一概念来存储具有独特访问模式的隔离数据。
在 [第 13 章](ch13.md) 中，我们将探讨资源如何相互引用，以及如何维护这些引用的一致性。
在 [第 14 章](ch14.md) 和 [第 15 章](ch15.md) 中，我们将仔细研究管理资源之间多对多关系的两种不同方式（使用关联资源或自定义的添加和移除方法）。
最后，在 [第 16 章](ch16.md) 中，我们将研究多态资源，它提供了一种独特的能力，使资源能够根据特定参数承担多种角色。
