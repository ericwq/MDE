# 第 2 部分 设计原则

我们 API 设计工具箱中的工具并非都是设计模式。
在接下来的几章中，我们将探讨 API 设计中的一些主题，它们不完全符合设计模式的定义（如 [第 2 章](ch2.md) 中所定义），
但对于指导我们构建优秀 API（如 [第 1 章](ch1.md) 中所定义）的旅程仍然重要且有帮助。

在 [第 3 章](ch3.md) 中，我们将探讨 API 不同组件命名的指导原则。
接下来，在 [第 4 章](ch4.md) 中，我们将介绍如何逻辑地排列这些组件并定义它们之间的关系。
最后，在 [第 5 章](ch5.md) 中，我们将探讨如何在 API 中可能需要的不同字段的众多数据类型之间做出决策。
