# 第 5 部分 集合操作

到目前为止，我们研究的大多数 API 设计模式都一次关注一两个资源。
在本节中，我们将超越这种狭隘的关注点，研究旨在处理更大资源集合的设计模式。

在 [第 17 章](ch17.md) 和 [第 23 章](ch23.md) 中，我们将探讨如何跨集合复制、移动、导入和导出资源，以及伴随这些功能而来的所有令人头疼的问题。
在 [第 18 章](ch18.md) 中，我们将学习如何应用标准方法集，通过批量操作而不是一次一个资源来处理资源块。
虽然我们可以将此思想应用于标准 delete 方法，但我们将在 [第 19 章](ch19.md) 中更进一步，研究如何通过对集合应用过滤器
（我们将在 [第 22 章](ch22.md) 中了解更多）而不是通过知道每个资源的唯一标识符来一次性删除许多资源。

在 [第 20 章](ch20.md) 中，我们将探讨如何加载用于聚合使用的数据点，而不是我们迄今为止所看到的资源的单个可寻址性。
在 [第 21 章](ch21.md) 中，我们将研究如何通过使用分页以可管理的方式处理大量资源。
