# 第 1 部分引言

API 设计是复杂的。
毕竟，如果它很简单，这本书可能就没有存在的必要了。
但在我们开始探索那些能使 API 设计更易于管理的工具和模式之前，我们首先必须就一些基本的术语以及本书的期望达成一致。
在接下来的两章中，我们将介绍一些入门材料，这些材料将作为我们在本书其余部分构建后续内容的基础。

我们将在 [第 1 章](ch1.md) 中详细定义我们所说的 API 的含义。
更重要的是，我们将探讨好的 API 是什么样的，以及如何将它们与差的 API 区分开来。
然后在 [第 2 章](ch2.md) 中，我们将更仔细地研究我们所说的设计模式的含义，以及本书其余部分所概述模式的组成部分，其最终目标是依靠这些设计模式来构建始终如一的优秀 API。
