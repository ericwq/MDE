# 关于封面插图

《API 设计模式》封面上的插图配文为 "Marchand d'Estampes à Vienne"，即“维也纳版画商人”。
该插图取自 Jacques Grasset de Saint-Sauveur（1757–1810）所著的《Costumes de Différents Pays》（不同国家的服饰），该书于 1797 年在法国出版。
每幅插图均经过精细绘制和手工上色。
Grasset de Saint-Sauveur 藏品中丰富的多样性，生动地向我们展示了就在 200 年前，世界上的城镇和地区在文化上是多么的不同。
<ins>彼时人们彼此隔绝，说着不同的方言和语言。
在街头或乡间，仅凭衣着就能轻易辨别出他们居住的地方以及他们的职业或社会地位。</ins>

<ins>自那时起，我们的着装方式已经发生了变化，而当时如此丰富多彩的地域多样性也已逐渐消失。
如今，我们已经很难区分不同大陆的居民，更不用说不同的城镇、地区或国家了。</ins>
也许我们是用文化多样性换取了更加多样的个人生活 —— 当然，也换取了一种更加多样化和快节奏的技术生活。

在这个人们难以区分一本计算机书籍与另一本的时代，Manning 通过基于两个世纪前由 Grasset de Saint-Sauveur 的画作重现的地域生活丰富多样性的封面，来庆祝计算机行业的创造力和进取精神。
